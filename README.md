# 🚀 MAXIMUS PANEL WEB

Panel de Administración Web independiente para la gestión de servidores VPS, clientes VPN (SSH/V2Ray/Trojan/WireGuard), revendedores y métodos de conexión de la aplicación móvil.

---

### 🌐 Instalación Automática en VPS (Ubuntu 20.04 - 24.04 LTS / Debian 11-12)

Ejecuta el siguiente comando en tu VPS para instalar e iniciar **MAXIMUS PANEL WEB** en el puerto **84**:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/JuandeMx/MAXIMUS-PANEL-WEB/main/install.sh)
```

Una vez finalizado, accede desde tu navegador:
- **URL**: `http://TU_IP:84`
- **Usuario por defecto**: `admin`
- **Contraseña por defecto**: `admin`

---

### 🛠️ Características Principales
- **Arquitectura Independiente**: Corre de forma aislada en Node.js (Puerto 84).
- **Categorías y Métodos para App**: Configuración completa por regiones con payload dinámico (`[IP]`, `[CF]`, `[CFT]`).
- **Multinodo VPS**: Agrega y administra múltiples servidores VPS remotos o locales.
- **Revendedores y Clientes**: Gestión completa de cuentas SSH/VPN y créditos.
- **Visualización Neón Moderna**: Interfaz dark mode responsiva de alta estética.
